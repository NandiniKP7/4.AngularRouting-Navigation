Sprint Workflow

Understand → Build → Test → PR → Complete

7+ Story Points / Sprint

Minimum sprint target

When I Get a Story

1

Understand

Give story + acceptance criteria to Claude and break it into small requirements.

2

Find Existing Pattern

Ask Claude to show me a similar feature/file already implemented in the repository.

3

Break Into Small Pieces

Decide which files change and implement one piece at a time.

4

Develop + Test

2–3 days

Develop → run → debug → test → continue to next piece.

5

PR + Review Comments

1–2 days

Raise PR → understand comments → update → retest → merge.

While My PR Is in Review

Test another developer's story Review another PR Prepare next story

Keep Learning

Daily Angular + TypeScript practice to understand office code better and become more independent.
